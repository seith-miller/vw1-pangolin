# Pangolin — Vehicle Systems Breakdown

## 1. Hull / Structure
- Hull shell (welded armor steel)
- Floor structure (mine blast geometry)
- Turret ring / weapon module interface
- Structural mounting points
- Access hatches (driver, commander)
- Recovery/tow points
- Drain plugs / sealing

## 2. Powertrain
- Engine
- Transmission
- Transfer case / final drives
- Driveshafts
- Fuel tank(s)
- Fuel lines and pumps
- Fuel filtration
- Exhaust system (with IR suppression)
- Air intake / filtration
- Engine cooling (radiator, fans, ducting)
- Engine mounts / vibration isolation

## 3. Suspension / Mobility
- Wheels and run-flat tires
- Axles
- Springs / dampers
- Steering system (power-assisted)
- Braking system (service and parking)
- Central tire inflation system (CTIS)
- Wheel hubs / bearings

## 4. Protection
### Passive
- Composite armor array (hull)
- Spall liners
- Underbody mine blast protection
- Turret / module armor
### Active
- Active protection system (APS)
- Laser dazzler / DIRCM (counter-FPV, counter-ATGM)
- Smoke grenade launchers (multispectral)
- Laser warning receivers
### Signature Management
- IR signature reduction (exhaust, hull)
- Radar cross-section reduction
- Visual camouflage provisions
- Acoustic signature management

## 5. Weapon Module / Turret
- Turret structure
- Turret drive (traverse and elevation)
- Weapon mount and stabilization
- Autoloader / feed system
- Ammunition storage and handling
- Coaxial / secondary weapon mount
- Spent case management

## 6. Fire Control
- Ballistic computer
- Commander's independent sight (day/thermal/laser)
- Gunner's primary sight (day/thermal/laser)
- Laser rangefinder
- Target tracking (AI-assisted)
- Meteorological sensor (wind, temp, pressure)
- Muzzle reference system
- Weapon sensors / barrel wear monitoring

## 7. Sensors / Situational Awareness
- 360-degree camera system
- Thermal imagers
- Surveillance radar
- Acoustic shot detection
- Proximity / obstacle sensors
- Drone detection sensors

## 8. Communications
- Radios (HF, VHF, UHF — software-defined)
- Internal intercom
- Platoon data link (high-bandwidth, low-latency)
- Antenna systems
- GPS / inertial navigation
- Battle management system (BMS)
- Encryption / COMSEC

## 9. Crew Station
- 3 identical stations — any station can drive, fight, and command
- In practice: 1 commander + 2 crew, but single-operator capable
- Blast-attenuating seats (x3)
- Drive-by-wire controls (at each station)
- Displays / multi-function screens (at each station)
- Crew HMI (human-machine interface)
- Hatches with vision blocks
- Personal equipment stowage
- Emergency egress system

## 10. Electrical
- Generator / alternator
- Battery bank
- Power distribution unit
- Wiring harness
- Circuit protection / fusing
- Auxiliary power unit (APU) — TBD
- Connectors / junction boxes

## 11. Environmental
- HVAC (heating, cooling, ventilation)
- NBC filtration and overpressure system
- Hull insulation (thermal / acoustic)
- Crew ventilation

## 12. Software / AI
- Vehicle management system (engine, transmission, diagnostics)
- AI-assisted driving (autonomous movement modes)
- Sensor fusion engine
- Target detection and classification
- Threat prioritization
- Platoon coordination / swarm logic
- Health monitoring / predictive maintenance
- Software update infrastructure

## 13. Ancillary / Support
- External stowage racks
- Tool kit
- Tow cable / recovery equipment
- Fire suppression system (engine bay and crew)
- Jack / tire change equipment
- Camouflage net attachment points
- Lighting (blackout and convoy)
- Horn / warning devices
