# 003 — Disaggregated MBT Concept

**Status:** Accepted
**Date:** 2026-04-13

## Context
Modern battlefields are sensor-saturated with wide frontages and diverse threats. A single 70-tonne MBT concentrates all capability — firepower, protection, sensing — into one high-value target.

## Decision
Instead of one MBT, a platoon of 3-9 lighter vehicles on a common chassis collectively achieves the effect of a main battle tank. Each vehicle specializes via its weapon module while sharing a common platform.

## Rationale
- Distributes risk — losing one vehicle doesn't lose all capability
- Lighter vehicles are more deployable (C-130 compatible)
- Modularity allows mission-tailored platoon composition
- Multiple sensor platforms provide better situational awareness than one

## Weapon Module Variants
1. Autocannon (30mm) — direct fire
2. Mortar (120mm, NEMO-class) — indirect fire
3. Anti-aircraft — air defense
4. Loitering munition launcher — 6-12 near-vertical tubes

## Consequences
- Platoon coordination becomes critical — requires robust C2 and data sharing
- More vehicles means more crews, more logistics, more maintenance
- Each variant must work within the same chassis weight and dimension envelope
